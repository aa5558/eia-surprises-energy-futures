# Not results: development-data dry run

These files come from `locked_test.py --dry-run`, which exercised the locked-test script on
development data only (2012–2016, a period also used for model selection) to catch bugs before
the specification freeze. They are **not** out-of-sample evidence. The locked-test results are in
`reports/tables/phase7/` and `reports/figures/phase7/`.
